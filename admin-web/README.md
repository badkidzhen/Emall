# Emall 管理后台

Vue3 + Element Plus 管理后台源码，和 Django 后端 API 联调。

## 快速开始

```bash
npm install
npm run dev
```

默认地址：

```text
http://localhost:5173
```

Vite 默认把 `/api` 代理到 `http://127.0.0.1:8000`，如果后端地址不同，修改 `vite.config.js`。

## 登录账号

账号由后端 `python backend/manage.py seed_initial_data` 初始化生成。

| 用户名 | 密码 | 用途 |
|---|---|---|
| `demo_admin` | `demoAdmin123456` | 管理后台 |

## 菜单结构

左侧菜单已按以下分组实现：

- 数据中心
- 商品中心
- 订单售后
- 用户会员
- 分销团队
- 城市代理
- 奖金池
- 营销中心
- 财务结算
- 权限系统

菜单树来自后端 `/api/system/menus/`，菜单管理页面对应 `/api/system/menu-items/`。

## 已完成能力

- 用户管理、会员等级、实名认证审核
- 分类管理、商品管理、SKU 管理、规格模板、库存日志
- 订单管理、售后退款、发票、订单统计
- 营销管理：优惠券、团购、秒杀、购买记录
- 分销配置、佣金明细、团队管理、分销统计
- 城市代理申请审核、代理列表、区域业绩、代理佣金
- 奖金池、权重配置、分配记录、模拟测算
- 财务结算：提现审核、资金流水、平台收支、税务报表
- 权限系统：管理员、角色、菜单、日志
- 图片上传：商品封面、分类图标、Banner 等
