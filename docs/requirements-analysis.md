# 需求分析与模块拆分

来源：`D:\111文档\技师学院\项目\商城\分销商城_Python.md`，版本 V6.0。

## 项目定位

这是一个微信生态分销商城系统，核心目标是围绕实物商品交易，叠加二级分销、城市代理、团队管理、奖金池和营销工具。后端需要保证订单、库存、佣金、代理收益与奖金池结算的事务一致性。

## 角色

| 角色 | 后端关注点 |
|---|---|
| 普通用户 | 浏览商品、购物车、下单、优惠券 |
| 会员 | 等级权益、折扣、分销资格 |
| 分销商 | 一级/二级推广关系、佣金明细 |
| 团队长 | 团队统计、团队业绩、团队奖励 |
| 城市代理 | 区域代理申请、区域抽成、区域业绩 |
| 管理员 | 商品、订单、营销、财务、权限、审核 |

## 后端模块边界

| 模块 | 目录 | 首批职责 |
|---|---|---|
| core | `backend/apps/core` | 通用模型、统一响应、健康检查 |
| users | `backend/apps/users` | 用户、会员等级、分销关系字段 |
| catalog | `backend/apps/catalog` | 分类、商品、SKU、库存日志 |
| orders | `backend/apps/orders` | 购物车、订单、订单商品快照 |
| distribution | `backend/apps/distribution` | 团队统计、分销配置、佣金记录 |
| marketing | `backend/apps/marketing` | 优惠券、团购、秒杀活动 |
| agents | `backend/apps/agents` | 城市代理申请、代理区域 |
| rewards | `backend/apps/rewards` | 奖金池、权重规则、分配记录 |
| finance | `backend/apps/finance` | 钱包、资金流水、提现申请与审核 |

## MVP 优先级

1. 用户/会员/微信登录基础。
2. 商品分类、商品、SKU、库存。
3. 购物车、订单创建、订单状态流转。
4. 二级分销关系绑定与佣金记录。
5. 微信支付、退款和售后。
6. 优惠券、团购、秒杀。
7. 团队统计、城市代理、奖金池。
8. 管理后台 RBAC、菜单、报表。

## 关键风险

- 合规风险：必须限定二级分销，佣金来自真实商品利润，不做拉人头或静态收益承诺。
- 资金风险：佣金、代理收益、奖金池必须有冻结期、售后期和人工审核能力。
- 库存风险：秒杀与普通下单需要 Redis 原子扣减和数据库最终一致性。
- 数据风险：手机号、身份证、支付信息需要加密或脱敏展示。
- 性能风险：团队树、排行、订单统计应使用异步任务和 Redis 聚合。
